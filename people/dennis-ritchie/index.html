Dennis Ritchie

He built C and Unix — the invisible foundations nearly all modern software still stands on.

4 min read · 1970s–2000s

Contents

Part I — The story

The story

At Bell Labs in the early 1970s, Dennis Ritchie created the C programming language and, with Ken Thompson, co-created the Unix operating system. C struck a rare balance — powerful enough for system programming, portable enough to run anywhere — and became the language in which operating systems, compilers and countless programs are written. Unix's design philosophy of small, composable tools shaped virtually every operating system that followed.

The reach is staggering: Linux, macOS, iOS, Android and the servers running the internet all descend from or are written in Ritchie's work, yet he remained almost unknown to the public. He is a study in building foundational tools of lasting elegance, in the design virtue of simplicity and composability, and in the outsized, invisible influence of infrastructure that quietly outlives its louder applications.

Part II — The playbook

The playbook

Principle 1

Build the foundation, not the feature

Ritchie made the tools other software is built from.

Do this: Infrastructure outlasts applications; building the layer everyone else depends on is the deepest leverage.
Principle 2

Prize simplicity and composability

Unix favoured small tools that combine, over big monoliths.

Do this: Design small pieces that do one thing well and connect cleanly; the system stays flexible for decades.
Principle 3

Optimise for portability

C's portability is why it spread everywhere.

Do this: Make your work run in as many places as possible; reach compounds adoption.

Frequently asked questions

What did Dennis Ritchie create?

The C programming language and, with Ken Thompson, the Unix operating system — foundations that underlie nearly all modern operating systems and software, from Linux and macOS to Android and the servers of the internet.

Why does Ritchie's work matter so much?

C and Unix set the template for how software and operating systems are built; their descendants and the code written in C are everywhere, making him one of the most influential yet least publicly known figures in computing.
